# 06. Frontend plan: the Wethrfork dashboard

> **Superseded in layout (see `docs/DECISIONS.md` D36, D39 and D42):** the shipped dashboard is a full-screen satellite-style map: NASA Blue Marble base map and Natural Earth borders (India's point of view), both bundled; a frosted map menu top-left; round tools on the right; a timeline capsule at the bottom; a drawer for shocks and audit; plus Timeline Prime, Validation and About pages. The sections below remain the feature specification. The offline rule still holds: the base map is one bundled image, not tiles.

Owner: P3. Stack: React 18 + Vite + TypeScript, Zustand for state, ECharts for small charts, a hand-written `<canvas>`
grid renderer for maps. Everything bundled; works with Wi-Fi off.

---

## 1. Principles
1. **Live only**: every map comes from a live call to our `/simulate`. Nothing pre-rendered.
2. **Judge-first**: the judge should be able to compose a shock in two clicks and see a result in under 3 seconds.
3. **One story**: the speed-limit ring appears on every fork map; the limits verdict appears with every fork.
4. **Offline**: no CDN scripts, no web fonts, no map tiles. India outline is a bundled GeoJSON.
5. **Honest**: full deltas always drawn; uncertainty shown as stippling, never as hiding.

## 4. Map rendering (`MapCanvas`)
- Canvas sized to the container; each grid cell is a rectangle. Cell (i, j): `x = j * cw`, `y = (31 - i) * ch`
  (north up).
- Equirectangular projection is fine at this scale. Outline drawn by projecting GeoJSON lon/lat to the same mapping.
- Field values → colour via `colors.ts`. Default scales:
  | Channel | Display unit | Scale | Range |
  | --- | --- | --- | --- |
  | t2m | °C (K - 273.15) | sequential warm | 0 to 45 |
  | tp | mm/day | sequential blue, sqrt | 0 to 100 |
  | u10, v10 | m/s | diverging | -15 to 15 (or show wind arrows from both) |
  | msl | hPa (Pa / 100) | sequential | 990 to 1025 |
  | tcwv | kg/m² | sequential green-blue | 0 to 70 |
  | delta (any) | display unit | diverging, symmetric around 0 | auto from 98th percentile |
- Optional overlays: wind arrows every 3 cells (from u10, v10), stippling, the ring, the shock box, cyclone track,
  sensitivity contours, hover tooltip with value and units.
- Performance: 1,152 cells, redraw on every scrubber move in under 5 ms. Pre-convert rollouts to `Float32Array`.

## 5. Fork view (core feature)
- Three synced maps for the selected universe versus control: Control, Shocked, Delta.
- The day scrubber (1 to 10) and channel selector drive all three.
- Delta is always the full field. Stipple a cell if `|delta| > sigma_err[day-1][channel][i][j]`.
- Speed-limit ring: the set of cells within Euclidean distance `3 + 8 * day` of the shock's bounding box (the judge's
  radius), drawn as a dashed contour; a second, inner contour at `8 * day` (our hard reach) optional.
- Play button animates days at 1 per second.
- Multiple universes: list on the left, tree view below; selecting one changes the Shocked and Delta maps.

## 6. Shock composer
| Control | Values |
| --- | --- |
| Presets | Warm Bay +3 K (judge's warm_ocean), Monsoon stall (judge's monsoon_stall), Plant a cyclone, Heat dome Rajasthan, Dry Kerala |
| Shape | Box (drag on map) or Gaussian (click centre, radius slider 2 to 8 cells) |
| Channel | t2m, tp, u10, v10, msl, tcwv |
| Amplitude | absolute (in display units) or percent of current value |
| Physically consistent | when on: temperature shocks also scale tcwv by 1.07^dT over ocean cells; smooth edges (Gaussian taper) |
| Name | auto-generated, editable |
| Fork | builds `perturbation [6,32,36]` in physical units and calls the judge server + lab verdict in parallel |

Preset definitions (`lib/shocks.ts`):
- **Warm Bay**: exactly the kit's warm_ocean (+3 K t2m and +15% tcwv over lat 8..20, lon 82..94).
- **Monsoon stall**: exactly the kit's monsoon_stall (-40% u10 and v10 over lat 8..20, lon 65..75).
- **Plant a cyclone**: centre chosen by click (default 15 N, 88 E); msl Gaussian low `-2000 Pa * exp(-r²/(2·2²))`;
  winds from gradient-wind balance (`f = 2Ω sin φ`, Ω = 7.292e-5 s⁻¹, air density 1.2 kg/m³, cell size from cos lat)
  rotated 15° inward (counter-clockwise flow); tcwv +20% inside radius 3. Track = argmin msl each day within 6 cells of
  the previous centre.
- **Heat dome**: +5 K t2m Gaussian radius 4 over 27 N, 72 E; msl -300 Pa.
- **Dry Kerala**: tcwv -30% Gaussian radius 2 over 10 N, 76.5 E.

## 7. Limits verdict panel
- On every fork, call `POST lab/verdict` with the same inputs.
- Show the four checks as ticks or crosses; numbers: near fraction day 1, far fraction max, growth ratio, max z.
- OOD meter: three levels (inside < 3σ, edge 3 to 5σ, extrapolating > 5σ) with the number.
- "Similar shocks in our fuzz test: n passed / N".
- If the lab is offline: grey panel with "Lab offline: checks run in CI" and a link to the Validation tab.

## 8. Impact cards
- Regions from `public/regions.json` (about 12: Kerala, Coastal Karnataka, Konkan & Goa (Mumbai), Gujarat, Rajasthan,
  Punjab-Haryana-Delhi, Uttar Pradesh, Bihar, West Bengal, Odisha, Andhra Pradesh, Tamil Nadu, Assam & North-East,
  Madhya Pradesh, Maharashtra interior). Each region is a list of cells (land_sea_mask ≥ 0.5).
- Heavy-rain probability: per cell, `P(tp > T) = 1 - Φ((T - f) / σ)` where f is the forecast in log1p space and σ the
  error in log1p space (`sigma_err` converted; precompute a log-space error map in `compute_sigma_err.py`). Region value
  = mean over cells. Thresholds selectable: 10, 35, 64.5 mm/day (IMD "heavy" starts at 64.5 mm/day; at 1° daily means
  this is rare, so 35 is the default).
- Heat probability: `P(t2m > T)` with T selectable (default 35 °C daily mean, also 40 °C).
- Show base probability, shocked probability, and the shift in percentage points, for the selected day.
- Kharif crop stress (JJAS windows): over land cells, a simple index `stress = clip(-rain_anomaly_ratio, 0, 1) +
  clip((t2m - 33 °C)/5, 0, 1)` averaged over the first 10 days; show base versus shocked.
- Always label: "Probabilities use our measured 2021 forecast error; 1° cells (~110 km)."

## 9. Timeline Prime tab
- Held-out window (2021) from the lab with truth. Side-by-side model versus reality, synced scrubber.
- Sparkline of RMSE by lead versus persistence and climatology (from the self-grade JSON shipped as a small file in
  `dashboard/public/selfgrade.json`; aggregate numbers only, no per-day data).

## 10. Validation tab
- Natural experiment: two maps (observed composite and model response) for tp and msl deltas at day 2, pattern
  correlation, number of events.
- Fuzz heatmap: pass rate by channel × amplitude bucket, and by season.
- Light cone: the figure from `evaluation/report.py` (PNG in `dashboard/public/figures/`).

## 11. State model (Zustand)
```ts
type Universe = {
  id: string; name: string; parentId: string | null;
  perturbation: Float32Array | null;      // 6*32*36
  rollout: Float32Array[][] | null;       // [day][channel] -> Float32Array(1152)
  verdict: Verdict | null; status: 'idle'|'loading'|'ready'|'error';
};
type Store = {
  meta: Meta | null; windowId: string | null; init: Float32Array | null; doySinCos: [number, number] | null;
  universes: Record<string, Universe>; selectedUniverse: string; day: number; channel: Channel;
  labOnline: boolean; judgeOnline: boolean; lastLatencyMs: number | null;
};
```

## 12. Build and run

- `npm run typecheck`, `npm run lint` in CI.
